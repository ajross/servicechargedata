# Data Source

The 2023–2024 data was supplied in separate block and mapsite CSVs on 14 April 2025 in response to a [Freedom of Information request](https://www.whatdotheyknow.com/request/actual_service_charge_costs_for_8). Original files are available in `Original Data`.

`2023-2024.csv` contains 877 block/property-group records, associated mapsite charges, GRVs and supplied leasehold counts. `mapsites.csv` contains all 176 mapsite charge records, including nine with no associated block in the supplied block list.

Some block records have codes rather than confirmed address ranges. The source's unallocated-property groups have no supplied GRV. Boiler points and total-property counts are unavailable for this year. Definitions and calculation guidance are in the [borough README](../README.md).
