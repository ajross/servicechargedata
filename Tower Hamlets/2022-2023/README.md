# Data Source

The 2022–2023 workbook was supplied on 15 August 2024 in response to the [Tower Hamlets FOI request](https://www.whatdotheyknow.com/request/actual_service_charge_costs_for_4). The original is in `Original Data`.

`2022-2023.csv` contains 874 block records, associated mapsite charges, GRVs, property counts and available boiler points. `mapsites.csv` contains all 174 mapsite charge records, including eight with no associated block in the supplied block list.

The workbook includes unusually large aggregated amounts. Definitions, charging rules and limitations are described in the [borough README](../README.md).
